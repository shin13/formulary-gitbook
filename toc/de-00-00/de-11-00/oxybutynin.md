# Oxybutynin

## Apohide lotion 20%, 4.5mL

##### 臨採

| TAH Drug Code      | [EAPO](https://www.tahsda.org.tw/drugs/hissearch.php?drug_code=EAPO)                                                                                                                                                                                                                              |
|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Indications        | For primary palmar hyperhidrosis patients aged 12 and older.                                                                                                                                                                                                                                      |
| Dosing             | Apply an appropriate amount to both palms once daily before bedtime. Recommended dose is 5 pumps per palm (approximately 96 mg/day). Avoid application to body parts other than the palms.                                                                                                        |
| Hepatic Impairment | Dose adjustment not necessary                                                                                                                                                                                                                                                                     |
| Renal Impairment   | Dose adjustment not necessary                                                                                                                                                                                                                                                                     |
| Contraindications  | Narrow-angle glaucoma, urinary retention, severe heart disease, gastric outlet, duodenal or small intestinal obstruction. Paralytic ileus, reduced gastrointestinal motility, gastric or intestinal atony, myasthenia gravis. History of hypersensitivity to ingredients, breastfeeding patients. |
| Adverse Effects    | Thrombocytopenia, urinary retention, paralytic ileus, application site dermatitis, application site eczema, dry mouth, asteatosis, compensatory sweating.                                                                                                                                         |
| Pregnancy          | No (Limited) Human Data – Animal Data Suggest Low Risk                                                                                                                                                                                                                                            |
| Lactation          | No (Limited) Human Data - Probably Compatible                                                                                                                                                                                                                                                     |
| More Info          | [UpToDate](https://www.uptodate.com/contents/oxybutynin-drug-information)                                                                                                                                                                                                                         |
